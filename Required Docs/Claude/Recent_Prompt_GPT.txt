============================================================================
REQUIREMENTS
============================================================================

----------------------------------------------------------------------------
1. DATASET ROOT
----------------------------------------------------------------------------

Create a new dataset structure.

Example

Version9/

    data/

        vision_dataset/

            run_<timestamp>/

                images/

                annotations/

                metadata/

                previews/

                dataset_manifest.json

Each execution generates a complete reusable dataset.

No dependency on production web_runs.

Research dataset remains separate.

----------------------------------------------------------------------------
2. DXF RENDERING
----------------------------------------------------------------------------

Render the framing/reinforcement drawing into clean images.

Use vector rendering.

Do NOT use screenshots.

Maintain high resolution.

Rendering should preserve

beam lines

text

leaders

dimensions

reinforcement callouts

symbols

Generate

PNG

(or another lossless format)

for downstream AI models.

----------------------------------------------------------------------------
3. AUTOMATIC BEAM CROPPING
----------------------------------------------------------------------------

For every discovered beam

Generate

Beam_B1.png

Beam_B2.png

Beam_B3.png

...

Cropping should include

beam geometry

nearby annotations

leader lines

support regions

stirrups

development bars

curtailments

with configurable padding.

Do NOT crop text away.

The crop should represent what a human estimator would inspect.

----------------------------------------------------------------------------
4. ANNOTATION JSON
----------------------------------------------------------------------------

For every beam image

Generate

Beam_B17.json

using deterministic engineering outputs.

Example

{
    "beam_id": "B17",

    "drawing": "Framing",

    "bbox": [...],

    "annotations": [

        {
            "text": "2Y20",

            "role": "Top Main",

            "source": "Deterministic",

            "confidence": 1.0
        },

        {
            "text": "8Ø@100",

            "role": "Support Stirrup",

            "source": "Deterministic",

            "confidence": 1.0
        }

    ]
}

Do NOT invent labels.

Only export labels already known by the deterministic pipeline.

----------------------------------------------------------------------------
5. METADATA EXPORT
----------------------------------------------------------------------------

Generate metadata for every beam.

Include

beam id

drawing name

beam dimensions

beam orientation

bounding box

engineering phases used

number of annotations

roles discovered

diameters

stirrup presence

generation timestamp

MODEL_VERSION

This metadata will later support benchmarking.

----------------------------------------------------------------------------
6. DATASET MANIFEST
----------------------------------------------------------------------------

Generate

dataset_manifest.json

containing

dataset version

generation date

drawing names

number of beams

number of annotations

roles exported

image resolution

dataset statistics

Example

{

    "dataset_version": "9.0.0",

    "beams": 65,

    "images": 65,

    "annotations": 412,

    "roles": {

        "Top Main": 80,

        "Bottom Main": 78,

        "Stirrup": 132

    }

}

----------------------------------------------------------------------------
7. VISUAL PREVIEW
----------------------------------------------------------------------------

Generate preview images.

Example

Beam_B17_preview.png

showing

beam crop

annotation boxes

beam id

role labels

This is for dataset quality inspection only.

Do NOT generate training labels visually.

Keep original images clean.

----------------------------------------------------------------------------
8. ENGINEERING TRACEABILITY
----------------------------------------------------------------------------

Every annotation shall contain

where it came from

Example

{

    "source_phase": "R3",

    "source_object": "...",

    "engineering_confidence": 0.97

}

Maintain complete traceability back to the deterministic pipeline.

----------------------------------------------------------------------------
9. DATASET QUALITY CHECK
----------------------------------------------------------------------------

Generate validation report.

Verify

Every beam has image

Every image has JSON

Every JSON references valid beam

No duplicate beam ids

No orphan annotations

No missing metadata

Produce

dataset_validation.json

without redesign.

Only prepare architecture.
