## Setup

```powershell
pip install -r requirements.txt
cd Version10
$env:PYTHONPATH="src"
```

## Quick start

```powershell
cd Version10
python Run_PY/run_phase_vroot1_dynamic_pipeline_initialization.py
```

Outputs: `Version10/data/output/` (offline) or `Version10/data/web_runs/<run_id>/` (web).

cd Version10\webapp
