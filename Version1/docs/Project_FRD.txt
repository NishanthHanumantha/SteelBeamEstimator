# Steel Beam Estimation Automation

Objective:
Read DXF files and estimate beam steel quantity in KG and MT using Cursor Pro.

Inputs:(1 set of drawing - 3 drawings Below)
1. General Notes DXF
2. Beam Framing Plan/Drawing
3. Beam Reinforcement Plan/Drawing

Outputs:
1. Beam-wise Steel Quantity
2. Diameter-wise Steel Quantity (Dia)
3. Total Steel KG
4. Total Steel MT

Estimator Output Excel:
Have this output sheet for reference so that we can build a model to generate results close to this output sheet prepared by estimators.
