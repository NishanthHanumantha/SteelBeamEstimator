Vision preferred:
Target → Layer → Physical Groups → Bar Count → Diameter → Specification → MAIN/EXTRA → Support Scope → Visual Stirrup Identification.

Deterministic authority:
Geometry → Spacers → Cut Length → Development Length → Anchorage → Hooks/Bends → Stirrup Quantity/Engineering → Pieces → Weight → BBS → Excel.

The important design principle is that Vision decides what reinforcement exists, while the deterministic engine decides how that reinforcement is engineered and quantified.
